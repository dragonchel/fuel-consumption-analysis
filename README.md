## 1. О проекте

Проект представляет собой настольное приложение для анализа данных о рейсах грузового транспорта. Система загружает сведения из Excel-файла, проверяет корректность данных, строит регрессионную модель расхода топлива и рассчитывает индивидуальные показатели для каждого рейса.

Основные результаты работы программы:

- прогнозный расход топлива;
- верхняя допустимая граница расхода;
- список рейсов с потенциальным перерасходом;
- величина избыточного расхода;
- дополнительные выбросы CO₂;
- условная оценка экологического ущерба;
- PDF-отчёт по результатам анализа.

## 2. Актуальность

Топливные затраты занимают значительную долю эксплуатационных расходов автотранспортных и логистических предприятий. При большом количестве автомобилей и рейсов ручная проверка расхода топлива становится трудоёмкой и может приводить к пропуску аномальных наблюдений.

Использование статистической модели позволяет сравнивать фактический расход не с одной усреднённой нормой, а с расчётным значением, учитывающим параметры конкретного рейса. Это помогает выявлять случаи, которые требуют дополнительной проверки технического состояния автомобиля, маршрута или условий эксплуатации.

## 3. Цель работы

Разработать программный комплекс для анализа расхода топлива при грузоперевозках на основе методов корреляционно-регрессионного анализа.

## 4. Постановка задачи

В качестве исходных данных используется Excel-таблица со сведениями о рейсах грузового транспорта.

Для каждого наблюдения необходимо:

1. загрузить и проверить исходные данные;
2. проверить наличие обязательных столбцов и пропущенных значений;
3. исследовать распределения числовых признаков;
4. оценить взаимосвязи между параметрами рейса и расходом топлива;
5. построить парную и множественную регрессионные модели;
6. проверить статистическую значимость и качество моделей;
7. рассчитать ожидаемый расход топлива для каждого рейса;
8. определить допустимую верхнюю границу расхода;
9. выявить рейсы с потенциальным перерасходом;
10. сформировать итоговый отчёт.

Обязательные признаки входного файла:

| Столбец | Описание |
|---|---|
| `Вес транспорта, т` | Масса грузового транспорта в тоннах |
| `Скорость, км/ч` | Скорость движения в километрах в час |
| `Расход топлива, л/100 км` | Фактический расход топлива на 100 км |

## 5. Математическая модель

В качестве результативного признака используется расход топлива, а в качестве факторов — вес транспорта и скорость движения.

Общий вид множественной линейной регрессии:

$$
y = b_0 + b_1x_1 + b_2x_2 + \varepsilon
$$

где:

- `y` — расход топлива, л/100 км;
- `x₁` — вес транспорта, т;
- `x₂` — скорость движения, км/ч;
- `b₀` — свободный член;
- `b₁`, `b₂` — коэффициенты регрессии;
- `ε` — случайная ошибка.

Итоговая модель, полученная по исследуемой выборке:

$$
\hat{y} = 22{,}11 + 0{,}41x_1 - 0{,}11x_2
$$

Коэффициенты модели оцениваются методом наименьших квадратов.

## 6. Анализ исходных данных

В исследовании использовался набор данных по 223 рейсам грузового транспорта.

Анализируемые признаки:

- вес транспорта;
- скорость движения;
- расход топлива в литрах на 100 км.

Перед построением моделей выполняются следующие этапы обработки:

- загрузка данных из Excel;
- проверка структуры входной таблицы;
- проверка наличия обязательных столбцов;
- проверка числового формата значений;
- обнаружение пропущенных значений;
- формирование матрицы факторов `X` и целевой переменной `y`.

Для проверки распределений применяется критерий Шапиро–Уилка при уровне значимости `α = 0,05`. С учётом отклонений отдельных признаков от нормального распределения для анализа взаимосвязей используется коэффициент корреляции Спирмена.

## 7. Регрессионный анализ

В работе сравниваются две модели.

### Парная регрессия

В парной модели расход топлива зависит только от веса транспорта:

$$
\hat{y} = 14{,}64 + 0{,}41x
$$

Коэффициент при весе транспорта показывает, что увеличение массы на одну тонну связано со средним увеличением расчётного расхода примерно на `0,41 л/100 км`.

### Множественная регрессия

В множественную модель включаются вес транспорта и скорость движения:

$$
\hat{y} = 22{,}11 + 0{,}41x_1 - 0{,}11x_2
$$

Знак коэффициента при скорости интерпретируется только в рамках рассматриваемой выборки и не является универсальным физическим правилом для всех условий эксплуатации.

## 8. Оценка качества модели

Основные результаты сравнения моделей:

| Показатель | Парная модель | Множественная модель |
|---|---:|---:|
| Факторы | Вес транспорта | Вес транспорта, скорость |
| `R²` | 0,5191 | 0,5427 |
| Нормированный `R²` | 0,5178 | 0,5386 |
| Стандартная ошибка | 1,8914 | 1,8506 |
| F-статистика | 239,3609 | 130,5622 |
| Значимость F | 4,49 · 10⁻³⁷ | 4,15 · 10⁻³⁸ |
| Количество наблюдений | 223 | 223 |

Множественная модель объясняет около `54,3%` изменчивости расхода топлива. После добавления скорости движения коэффициент детерминации увеличился с `0,5191` до `0,5427`, а стандартная ошибка уменьшилась с `1,8914` до `1,8506`.

В программной реализации данные дополнительно разделяются на обучающую и тестовую выборки в соотношении 80/20. Для оценки устойчивости рассчитываются значения `R²` на обеих выборках и показатель RMSE.

## 9. Алгоритм выявления перерасхода

Для каждого рейса рассчитывается прогнозное значение:

$$
\hat{y}_i = 22{,}11 + 0{,}41x_{1i} - 0{,}11x_{2i}
$$

Верхняя допустимая граница определяется с учётом ошибки модели:

$$
y_{\text{верх},i} = \hat{y}_i + z \cdot RMSE
$$

где `z` — коэффициент, соответствующий выбранному уровню доверия. Для уровня доверия 95% используется значение `z ≈ 1,96`.

Величина перерасхода определяется по формуле:

$$
E_i = \max(y_{\text{факт},i} - y_{\text{верх},i}, 0)
$$

Если фактический расход не превышает верхнюю границу, перерасход принимается равным нулю. В противном случае рейс добавляется в список наблюдений, требующих дополнительной проверки.

## 15. Экологическая оценка

Для оценки дополнительных выбросов используется эмиссионный коэффициент:

$$
1\ л\ топлива = 2{,}68\ кг\ CO_2
$$

Дополнительные выбросы определяются следующим образом:

$$
CO_2 = E \cdot 2{,}68
$$

где `E` — величина перерасхода топлива.

Условный экологический ущерб рассчитывается по формуле:

$$
D = \frac{CO_2}{1000} \cdot 50
$$

где `50` — условная стоимость одной тонны CO₂, используемая для сравнительной оценки.

Экологический показатель предназначен для аналитической оценки и не является официальным расчётом экологического ущерба.

## 18. Пример работы

Пример входной записи:

| Номер рейса | Вес транспорта, т | Скорость, км/ч | Расход топлива, л/100 км |
|---:|---:|---:|---:|
| 1 | 33,80 | 63,72 | 28,93 |

Для этой записи расчётное значение по модели составляет примерно `28,96 л/100 км`. При верхней допустимой границе `32,56 л/100 км` фактический расход не считается перерасходом.

Пример потенциально проблемного рейса:

| Номер рейса | Вес транспорта, т | Скорость, км/ч | Фактический расход |
|---:|---:|---:|---:|
| 2 | 30,00 | 58,00 | 44,09 |

Расчётный расход составляет около `28,03 л/100 км`, верхняя допустимая граница — около `31,64 л/100 км`. Величина перерасхода составляет примерно `12,45 л/100 км`, поэтому рейс попадает в список для дополнительной проверки.
